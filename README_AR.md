# GE_Sky — منصة تشغيل التجارة الرقمية

نسخة تأسيسية عربية RTL لمنصة موحّدة تجمع التجارة الإلكترونية، CRM، التسويق، التحليلات، والأتمتة الذكية.

## التشغيل

```bash
pnpm install
pnpm dev
```

## الفحص والبناء

```bash
pnpm check
pnpm build
pnpm test
```

## الوحدات المتاحة

- مركز القيادة والنظرة العامة.
- المنتجات والكتالوج، مع البحث وإضافة مسودة.
- العملاء وCRM.
- الحملات التسويقية مع تبديل الحالة.
- التحليلات والتقارير.
- وكلاء الذكاء الاصطناعي.

للتفاصيل المعمارية وخطة المراحل، راجع [`PROJECT_MAP.md`](./PROJECT_MAP.md).
